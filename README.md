# Python Learning Journey

A comprehensive collection of Python programming modules and exercises, focusing on **Object-Oriented Programming**, **Text Analysis**, and **Core Fundamentals**[cite: 2]. This repository is primarily organized as a series of **Jupyter Notebooks**, providing an interactive learning experience with code, documentation, and results in one place[cite: 2].

---

## 📂 Repository Structure

The project is categorized into three specialized modules based on academic curriculum[cite: 2]:

### 1. ZTP (Advanced Programming Techniques)
Focuses on the Object-Oriented Programming (OOP) paradigm and structured data handling[cite: 2].
*   **Classes & Objects:** Defining blueprints and managing state[cite: 2].
*   **Inheritance:** Implementing hierarchical structures and code reuse[cite: 2].
*   **Data Persistence:** Working with **CSV** and **JSON** file formats for data storage and retrieval[cite: 2].

### 2. AEI (Automatic Information Extraction)
Practical implementation of Natural Language Processing (NLP) and text mining algorithms[cite: 2].
*   **Frequency Lists:** Statistical analysis of word occurrences[cite: 2].
*   **TF-IDF:** Quantifying the importance of words within a corpus[cite: 2].
*   **Information Theory:** Implementation of **MI** (Mutual Information) and **IG** (Information Gain) for feature significance[cite: 2].

### 3. IG (Python Introduction & GUI)
Core language foundations and preparation for Graphical User Interface development[cite: 2].
*   **Data Types:** Deep dive into Python's native structures like Strings, Lists, Dicts, and Sets[cite: 2].
*   **Control Flow:** Mastery of logic through conditional statements and efficient **Loops**[cite: 2].

## 🚀 How to Run

Since this repository consists of **Jupyter Notebooks** (`.ipynb`), you can interact with the code directly[cite: 2]:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Mifiszon/Python-Exercises.git](https://github.com/Mifiszon/Python-Exercises.git)
   ```
2. **Install Jupyter:**
   ```bash
   pip install notebook
  ```
3. **Install Jupyter:**
   ```bash
   pip install notebook
  ```
