# Python Learning Journey

A comprehensive collection of Python programming modules and exercises, focusing on **Object-Oriented Programming**, **Text Analysis**, and **Core Fundamentals**. This repository is primarily organized as a series of **Jupyter Notebooks**, providing an interactive learning experience with code, documentation, and results in one place.

---

## 📂 Repository Structure
.
The project is categorized into three specialized modules based on academic curriculum.

### 1. ZTP (Advanced Programming Techniques)
Focuses on the Object-Oriented Programming (OOP) paradigm and structured data handling.
*   **Classes & Objects:** Defining blueprints and managing state.
*   **Inheritance:** Implementing hierarchical structures and code reuse.
*   **Data Persistence:** Working with **CSV** and **JSON** file formats for data storage and retrieval.

### 2. AEI (Automatic Information Extraction)
Practical implementation of Natural Language Processing (NLP) and text mining algorithms.
*   **Frequency Lists:** Statistical analysis of word occurrences.
*   **TF-IDF:** Quantifying the importance of words within a corpus.
*   **Information Theory:** Implementation of **MI** (Mutual Information) and **IG** (Information Gain) for feature significance.

### 3. IG (Python Introduction & GUI)
Core language foundations and preparation for Graphical User Interface development.
*   **Data Types:** Deep dive into Python's native structures like Strings, Lists, Dicts, and Sets.
*   **Control Flow:** Mastery of logic through conditional statements and efficient **Loops**.
